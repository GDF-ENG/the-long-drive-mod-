# TLD 模组工坊 v6.1.2 · 完整功能介绍

> 非官方作品，基于开源项目 TLD Mod Installer 二次开发
> 许可证：AGPL-3.0 | 数据来源：Workshop TLD Mods（GPL-3.0）

## 一、这是什么

TLD 模组工坊（TLD Mod Workshop）是一款《The Long Drive》游戏模组管理工具，
把原来分散在创意工坊、整合包站、各处手动下载的模组流程，整合成一个网页界面。

**采用 Flask + Vue 3 架构**，全部逻辑跑在本地，打开浏览器就能用。

程序为**单文件 exe**，双击即自动启动服务器并打开网页，
不需要单独安装 Python，也不需要配置任何环境。
开源项目未打包有一个打包程序可适用
需要安装Python环境要改的话（不改的人请忽略）

---

## 二、界面结构

采用「首页分区」设计，所有功能集中在一页内，通过顶部分区切换条切换，
无需在多个页面之间来回跳转。

顶部分区依次为：

| 分区 | 功能 |
|---|---|
| 模组列表 | 浏览、筛选、批量安装全部官方模组 |
| **车间工具** | 独立的车间汉化版下载入口 |
| 模组包 | 官方整合包管理与导入导出 |
| 玩家整合包 | 玩家上传的整合包浏览与上传 |
| 玩家模组 | 玩家上传的单模组 |
| AI 推荐 | 根据关键词智能推荐模组 |
| 论坛 | 发帖、评论、点赞 |
| 已安装 | 已装模组的升级、更新、卸载 |

侧边栏同步提供各分区的快捷入口，并可折叠以扩大显示区域。

## 三、核心功能

### 3.1 模组列表

- 完整读取 Workshop 官方模组数据库，支持**英文源**与**本地中文源**切换
- 支持**严格模式**开关：开启后只显示中文模组，隐藏未汉化条目
- 分类筛选、关键词搜索、网格/列表两种视图自由切换
- 模组卡片直接显示图片、名称、作者、简介
- 冲突标记与依赖标记自动识别
-翻译还目前有些bug

### 3.2 一键安装与批量操作

- 单个模组点击即可下载安装，实时显示下载与安装进度
- 支持**批量选择**：全选、反选、已选数量显示
- 批量安装 / 批量卸载 / 批量更新
- 安装前自动做**冲突检测**，冲突模组给出明确提示
- 自动创建备份，配置里的备份文件名可自定义

### 3.3 依赖自动解析

安装带依赖的模组时，自动请求依赖清单，
明确列出哪些依赖已安装、哪些需要补装，避免装完不能用。

### 3.4 模组详情与冲突提示

点击任意模组打开详情弹窗，包含：图片、名称、作者、版本、分类、
简介、更新日志、依赖清单、冲突原因。

冲突信息用红色标注，说明冲突的模组与冲突原因。

### 3.5 自动翻译（v6.1.2 新增）

打开模组详情时，**自动**把英文名称与简介翻译成中文，
显示在原文下方并带「中文」标签，玩家无需手动操作。

- 名称与简介分别翻译
- 原文已是中文则自动跳过，不浪费请求
- 翻译结果必须确实含中文才回填，避免显示原文
- 失败自动重试一次，仍失败则静默跳过，**不影响查看原文**
- 同时保留手动「翻译」按钮

翻译走公共接口，无需 API Key。

持支持中文翻译

### 3.6 模组包（整合包）

- 读取官方整合包数据，支持网格/列表视图
- 支持**导出**整合包清单为txt
- 支持**导入**整合包清单，自动批量安装其中包含的模组

### 3.7 玩家整合包

- 登录后可上传自己的整合包
- 上传时填写名称、作者、简介、图片地址、视频/教程链接
- 支持上传压缩包文件
- 其他玩家可直接浏览与下载

### 3.8 玩家模组（v6.1.2 新增）

- 登录后可上传自己的**单个模组**
- 表单：模组名称、作者、版本号、分类、简介、图片地址
- 支持**上传模组文件**或**填写外部下载链接**（二选一）
- 格式白名单：`.unity3d` `.zip` `.rar` `.7z` `.tar` `.gz`
- 同名同版本自动拦截，避免重复上传
- 文件名过滤非字母数字字符，防止路径穿越
- 下载接口使用 `basename` 校验，只允许访问上传目录内文件
- **上传的模组会同时进入 AI 推荐的匹配池**

### 3.9 AI 推荐

输入关键词，从真实模组库中匹配推荐。

- 匹配范围：模组名称、简介、作者
- 数据来源：官方模组列表 + 玩家上传模组
- 命中后按下载量标注热度（High / Medium / Low）
- 支持中英文关键词（如搜「卡车」能命中「汽车 六档模组」）
- 结果去重，最多返回 15 条

### 3.10 论坛

- 发帖、回复评论
- 帖子与评论均支持点赞
- 登录后才能发布内容

### 3.11 情报发布

首页「游戏情报」区，玩家可**自行编写并发布**情报：

- 填写标题、内容、可选链接
- 发布后以卡片形式展示，可单独删除
- 数据保存在浏览器本地，刷新不丢失

### 3.12 车间工具（v6.1.2 独立分区）

独立的模组下载与管理工具，与主程序**互不影响**：

- 支持创意工坊 MOD 下载
- 自动检测 Steam 安装路径
- 可放在任意目录运行
- 下载后解压即用

独立成区而非塞进模组列表，避免玩家误认为是主程序的弹窗功能。

### 3.13 已安装管理

- 列出本机已安装的全部模组
- 支持单个卸载、批量卸载
- 支持批量检查更新并升级
- 显示安装来源与版本信息

## 四、界面与体验

### 4.1 透明玻璃风格

全站采用毛玻璃拟态设计：半透明背景 + 背景模糊 + 细边框，
支持深色/浅色/跟随系统三种主题。

### 4.2 主题与外观自定义

设置页可自定义：

- 主题模式（深色 / 浅色 / 跟随系统）
- 强调色
- 背景色
- 字号（小 / 中 / 大）

配置自动保存。

### 4.3 多语言

内置 6 种语言：中文、English、Français、Español、Русский、العربية，
可在设置页切换，语言偏好持久保存。
这个语言翻译有问题只支持中文修改者可自己修复此bug

### 4.4 设置页便捷返回

设置项较多，顶部提供**吸顶的「← 返回首页」按钮**，
无需向上滚动即可随时退出设置。

### 4.5 其他细节

- 公告弹窗带倒计时，未读完无法关闭
- 首页显示安装数、可用模组数、整合包数、当前数据源
- 滚动到一定位置时显示「回到顶部」
- 回到顶部按钮支持平滑滚动
- Toast 提示自动去重，避免刷屏
- 模组搜索支持类型切换（模组 / 整合包）

## 五、更新机制（v6.1.2 重写）

### 5.1 为什么重写

原版走 GitHub Releases，但上游仓库是原作者的，版本停在 v5.0。
一旦有人发布新 Release，点更新会用官方 exe 覆盖本程序，
导致本分支所有自加功能（透明 UI、玩家上传、情报发布等）全部丢失。

**故改为读取夸克网盘分享目录中的版本清单。**

### 5.2 工作方式

程序启动时读取网盘的 `version.txt`，与自身版本比较：

```
版本清单 v6.1.3  >  当前 v6.1.2   → 提示更新，附网盘下载链接
版本清单 v6.1.2  =  当前 v6.1.2   → 静默，不打扰
拉取失败 / 内容不是版本号         → 静默忽略，按已是最新版处理
```

### 5.3 版本号识别

版本号书写方式很宽松，以下都能正确识别为同一版本：

- `v6.1.2` / `6.1.2` / `V6.1.2` / `v6.1.2 `（带空格）
- `v6.1.2-beta`（忽略预发布后缀）
- `6.2`（两段式自动补零）

无效内容（HTML 页面、纯文本、空文件）会被识别并静默忽略。

### 5.4 发新版流程

发布新版本只需**修改网盘上的 `version.txt` 一个文件**，
所有客户端下次启动即会收到更新提示。

## 六、技术实现

### 6.1 架构

```
launcher_v6.py        启动器（打包入口）
  └─ app.py           Flask 后端：全部 API 路由
       ├─ templates/index.html    Vue 3 前端（单页应用）
       ├─ static/style.css        毛玻璃风格样式
       └─ translations/*.json     6 语言文案

build_exe_v6.py       PyInstaller 打包脚本
unpack_exe.py         exe 解包工具（可反向提取资源）
```

### 6.2 单文件 exe 实现

所有资源打包进 exe 内部，运行时从内存文件系统读取。

**可写数据**（用户数据库、上传的图片与文件）存放到 exe 同级的
`.tld_data/` 隐藏目录，删除该目录即可完全清除运行数据。

启动器在后台线程运行 Flask，主线程等待，
**关闭窗口即停止服务器**，无需额外操作。

### 6.3 依赖

Flask、requests、SQLite（标准库）。
翻译走公共接口，AI 功能预留豆包接口配置但默认未启用。
